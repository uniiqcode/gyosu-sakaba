# 提灯の絵を ChatGPT に頼むプロンプト

2026-10-31。居酒屋の店頭に吊るす提灯として使う。添付する画像は2つ。

1. `design/chochin-reference.png` … 提灯に書く文字の見本（縦書き。ロゴの文字を並べたもの）
2. `site/assets/logo-mark.png` … ロゴ（文字の形の元）

```
添付した2つの画像をもとに、居酒屋の店頭に吊るす「提灯（ちょうちん）」の絵を作ってください。

■ 添付画像
1枚目：提灯に書く文字の見本です。縦書きで「業スー酒場」と並べてあります。
2枚目：お店のロゴです。文字の形はこのロゴと同じです。
文字の形・太さ・筆の勢いは、見本の文字をできるだけそのまま使ってください。別の書体に描き直さないでください。

■ 提灯
・白い紙の、縦長の丸い提灯（赤ちょうちんのような形。色は白）
・上と下に黒い枠（輪）、上に吊るすための金具とひも
・紙の骨（横の細い線）がうっすら見える程度の、落ち着いた描き方
・店の軒先に1つ吊るされている、正面から見た絵

■ 文字
・提灯の正面の中央に、縦書きで上から「業」「ス」「ー」「酒」「場」
・色は緑 #0B6E4F だけ（縁取り・影・グラデーションなし）
・「ス」と「ー」は小さく、2つ合わせて漢字1字ぶんの高さに収める。縦書きなので「ー」は縦の棒にする
・「ス」「ー」が小さくても、縦に並べた全体の中心線がまっすぐ通り、文字の間隔がそろって見えるように（見本と同じバランス）
・提灯のふくらみに合わせて、文字が少し丸みに沿って見えるとよい。ただし読みやすさを優先し、ゆがめすぎない

■ 色
提灯の紙は白、文字は緑 #0B6E4F、枠と金具は黒。それ以外の色は使わない。
背景は白か透明（切り抜いてウェブページに置くため）。

■ 出力
・縦長の画像（縦横比 2:3 程度）、提灯の上下に少し余白
・特定の企業のロゴや商標をまねないでください
```

## 確かめるところ

- 文字の形が見本と同じか（別の書体に描き直されていないか）
- 「ー」が縦棒になっているか、「ス」「ー」が小さくて全体の中心線がそろっているか
- 緑・白・黒以外の色（赤など）が入っていないか
