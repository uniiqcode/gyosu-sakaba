# 夜の路地の絵（ページ上部の背景）を ChatGPT に頼むプロンプト

2026-10-31。ページ上部のロゴのかわりに、背景として使う。添付する画像は1つ。

1. `design/chochin-chatgpt-original.png` … 採用した「業スー酒場」の提灯の絵

```
添付した提灯の絵を使って、夜の路地の酒場の風景を作ってください。ウェブページの一番上に置く、横長の背景画像にします。

■ 場面
・夜の細い路地。石畳か古いアスファルトの道が、手前から奥へまっすぐ続く
・道の両側に、お酒を出す小さな飲食店（居酒屋・小料理屋・立ち飲みなど）が数軒ずつ並ぶ。木の格子戸、のれん、小さな看板、赤ちょうちんなど
・左側のいちばん手前の店の軒先に、添付した白い提灯が1つ下がっている

■ 「業スー酒場」の提灯（いちばん大事）
・添付の提灯をそのまま使う。形、黒い枠、縦書きの緑の文字「業スー酒場」（「スー」は横並び）を変えない
・文字は緑 #0B6E4F のまま。描き直したり、別の文字にしたりしない
・提灯は道の方へ少し向きを変え、見る人（道の手前）から文字が読めるようにする
・内側から弱い白熱電球で照らされ、白い紙がほんのり温かい色に光っている。明るすぎず、まわりの闇に少しにじむ程度

■ 光と雰囲気
・夜の街の照明（ほかの店の赤ちょうちん、すりガラス越しの店の明かり、遠くの街灯）と合わせて、全体は落ち着いた暗さ
・提灯のやわらかい光が、哀愁のある、少しさみしく温かい雰囲気をつくる
・雨上がりで道が少し濡れ、明かりがうっすら映り込んでいる。薄いもや
・空や奥の方は深い紺色。暖かい明かり（橙・琥珀色）と夜の紺の対比

■ 気をつけること
・ほかの店の看板やのれんの文字は、ぼかして読めないようにする（実在の店名・企業のロゴ・商標を入れない）
・人は入れないか、入れても遠くの小さな後ろ姿だけ（顔がわかる人物は入れない）
・写真のようにリアルで、映画のワンシーンのような落ち着いた絵。イラスト調・アニメ調にしない

■ 構図と大きさ（ウェブページの背景に使うため）
・横長 1536×1024 ピクセル（3:2）
・「業スー酒場」の提灯は、左側の、左端から画面の幅の4分の1ほど内側に置く（端に寄せすぎない。スマートフォンでは左右の端が少し切れるため）
・提灯は画面の高さの半分ほどの大きさで、上下が切れないようにする
・画面の下の4分の1ほどは暗めにして、白い文字を重ねても読めるようにする
```

## 確かめるところ

- 提灯の文字が「業スー酒場」のまま崩れていないか、緑のままか
- 提灯が手前から読める向きになっているか
- ほかの店の看板に、読める文字や実在の店名が入っていないか
- 下の方が暗めで、白い文字を重ねられそうか
