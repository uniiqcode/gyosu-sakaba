# 路地の絵の提灯の文字を、曲面と灯りになじませるプロンプト

2026-11-01。`design/alley-chatgpt-original.png` の提灯の文字が平らに見える（シールを貼ったよう）ので、文字だけを描き直してもらう。添付するのは `design/alley-chatgpt-original.png`。

```
添付した画像を編集してください。左手前の白い提灯に書かれた緑の文字「業スー酒場」だけを描き直し、それ以外（提灯の形・路地・明かり・構図・色・大きさ 1536×1024）は変えないでください。

■ 今の問題
文字が提灯の表面に貼り付けたシールのように平らで、提灯の丸みや灯りと合っていません。
提灯の紙に、筆で直接書いて染み込ませた文字に見えるようにしてください。

■ 文字の形と並び（変えないこと）
・縦書きで上から「業」「スー」「酒」「場」。「スー」は小さく横並びのまま
・文字の形・太さ・筆の勢いは今のまま。別の書体にしない、文字を足したり減らしたりしない

■ 曲面に沿わせる
・提灯は横から見ると円筒形にふくらんでいて、少し道の方へ向いています。文字も紙の曲面に沿って曲げてください
・横方向: 文字の中心から左右の端に向かうほど、曲面が向こうへ回り込むので、文字の横幅が少しずつ詰まって見える
・縦方向: 提灯は上と下ですぼまっているので、上の「業」と下の「場」は、中央の文字より少し小さく、上下につぶれて見える。字の上側・下側の線が、すぼまりに合わせてわずかに弧を描く
・提灯の横の骨（細い横線）が文字の上にもうっすら透けて見え、紙の凹凸で字の線がわずかに波打つ

■ 灯りと緑の濃淡
・提灯は内側から弱い白熱電球で照らされています。光がいちばん強い中央付近は、紙を通した光で緑が明るく少し黄みがかって透ける
・光が弱くなる左右の端と、上下の黒い枠に近いところは、緑が深く暗くなる
・墨（緑のインク）が和紙に染み込んだように、輪郭はわずかににじみ、線の中にも少し濃淡がある
・緑の基本の色は #0B6E4F。暖かい灯りの下で少しオリーブ寄りに見えてもよいが、緑とわかる色を保つ。蛍光のような明るい緑にはしない

■ 出力
・元の画像と同じ構図・大きさ（1536×1024）
・提灯の文字以外は描き直さない
```

## うまくいかない時

- ほかの所まで変わる: ChatGPT の画像編集で提灯の文字の部分だけを選んで（範囲を塗って）から送る
- 文字の形が崩れる: `design/chochin-reference.png` も添付し、「文字の形は2枚目の見本と同じに」と足す
- 曲がりが強すぎる・弱すぎる: 「もう少し控えめに」「もう少し強く」と伝える

## 2回目（2026-11-01）

```

■ 直してほしいこと

提灯は円筒形で、見る人から見て右側の面が向こうへ回り込んで遠ざかっています。文字も、その曲面に沿って右側ほど遠くに見えるようにしてください。

・文字の列の中心線を、提灯の中心より少し左に置く
・各文字の右半分は、左半分より横幅を狭くする（右へいくほど少しずつ詰まる）
・右側の線は、左側の線より少し細く、少し暗い緑にする（光が回り込みにくいため）
・左側の線は、少し広く、明るめに
・上の「業」と下の「場」は、提灯のすぼまりに合わせて少し小さく、字の上下の線がわずかに弧を描くのは今のまま

■ 変えないこと
・文字の形・太さ・並び（縦書きで「業」「スー」「酒」「場」、「スー」は小さく横並び）
・緑の色と、灯りによる濃淡
・提灯の形、路地、明かり、構図、大きさ（1536×1024）
・提灯の文字以外は描き直さない
```

## 3回目（2026-11-01）

2回目の結果 `design/alley-lantern-text-v3.png` は少し良くなった。人の希望で、路地から文字が読みやすいよう、提灯そのものを右（路地の方）へ少し回す。文字の見え方（右が手前・左が向こう）と光の当たり方も変わる。同じ会話で続けて送る。

```
ありがとうございます。文字の色と濃淡の付け方は良くなりました。次は、提灯そのものの向きを変えてください。

■ 直してほしいこと
提灯を、吊るしている金具を軸にして、右（路地の奥の方、道の真ん中の方）へ少し回してください。回す角度は20〜30度くらいです。
路地を歩いてくる人から、提灯の文字が正面に近い角度で読めるようにしたいです。

■ 回したことで変わるところ（自然に変えてください）
・文字の列は、提灯の中心線より少し右に移る
・文字の右半分は手前に来るので広く明るく、左半分は向こうへ回り込むので狭く少し暗くなる
・上の「業」と下の「場」は、提灯のすぼまりに合わせて少し小さく、字の上下の線がわずかに弧を描く
・提灯の横の骨（細い横線）と、上下の黒い枠の楕円も、回した向きに合わせて見え方が変わる
・灯り: 内側の白熱電球の光は、正面（文字のある面）の中央がいちばん明るく、左の端へ回り込むほど暗い。路地の街灯やほかの店の明かりが、提灯の右側をわずかに照らす
・壁や軒に落ちる提灯の光と影も、向きに合わせて少し変わる

■ 変えないこと
・文字の形・太さ・並び（縦書きで「業」「スー」「酒」「場」、「スー」は小さく横並び）
・緑の色（#0B6E4F を基本に、灯りで濃淡）。和紙に染み込んだような質感
・提灯の大きさと吊るしている位置、路地、ほかの明かり、構図、画像の大きさ（1536×1024）
・提灯とその光の当たり方以外は描き直さない
```
