# 業スー酒場｜居酒屋の一品ネタ帳（非公式）

業務スーパーの食材を使った料理とレシピへの**リンク集**。小さな居酒屋の店主（料理人）が、業務スーパーで仕入れた食材をメニューに展開するときの、アイデアのきっかけにしてもらうためのページ。

> 業務スーパー（株式会社神戸物産）とは関係のない、非公式のページです。

## 方針

| 項目 | 内容 |
|------|------|
| 対象 | 小規模の居酒屋の店主（料理人） |
| 載せるもの | 業務スーパーの食材を使った料理の名前と、レシピが載っているページへのリンク |
| 載せないもの | レシピの本文、元のページの文章・コメント・画像の転載。レシピは元のサイトで見てもらう |
| 情報源 | YouTube（タイトル・説明欄・コメントから判断。動画は見ない）、ブログ・ホームページ（RSS など） |
| 更新 | 1日1回、自動で探し、新しいものと見逃していたものを「新着」として追加 |
| 判定 | 無料で行う（キーワードで絞る＋人がマージ前に目で確かめる）。AI の API は使わない |
| 場所 | GitHub（公開リポジトリ）。ページは GitHub Pages、自動更新は GitHub Actions |
| 人の作業 | 毎日届く PR を確かめてマージするだけ |
| 収益 | なし（アフィリエイトではない） |

## 毎日の流れ（予定）

1. 毎朝、GitHub Actions が自動で動く
2. YouTube・ブログから新しい記事を探し、すでに載せたものを除く
3. キーワードで「業務スーパーの食材を使った料理か」「レシピがあるか」を絞り、食材・料理の種類で分ける
4. 新着をまとめた PR が1本届く → 人が確かめてマージ
5. マージすると自動でページが更新される

## 名前

- 表示名: **業スー酒場**、サブタイトル: **居酒屋の一品ネタ帳（非公式）**
- リポジトリ: `uniiqcode/gyosu-sakaba`（ページの URL は `https://uniiqcode.github.io/gyosu-sakaba/` の予定）
- 同じ名前のお店・サイト・アカウントは見つからなかった。「業スー」は J-PlatPat で確認し問題なし（2026-10-30）

経緯と決まっていないことは `STATUS.md` を読む。
