# 業スー酒場｜居酒屋の一品ネタ帳（非公式）

業務スーパーの食材を使った料理とレシピへの**リンク集**。小さな居酒屋の店主（料理人）が、業務スーパーで仕入れた食材をメニューに展開するときの、アイデアのきっかけにしてもらうためのページ。

> 業務スーパー（株式会社神戸物産）とは関係のない、非公式のページです。

## 方針

| 項目 | 内容 |
|------|------|
| 対象 | 小規模の居酒屋の店主（料理人） |
| 載せるもの | 業務スーパーの食材を使った料理の名前と、レシピが載っているページへのリンク |
| 載せないもの | レシピの本文、元のページの文章・コメント・画像の転載。レシピは元のサイトで見てもらう |
| 情報源 | YouTube（タイトルと概要欄から判断。動画は見ない）、ブログ・ホームページ（RSS） |
| 更新 | 毎日自動で探してストックにため、人が頼んだ時に7日分の候補を出す。載せる日が来ると1日1品ずつ「新着」に出る。投稿日が新しいものから |
| 判定 | 無料で行う（キーワードで絞る＋人がマージ前に目で確かめる）。AI の API は使わない |
| 場所 | GitHub（公開リポジトリ）。ページは GitHub Pages、自動更新は GitHub Actions |
| 人の作業 | 7日分の候補の PR を確かめてマージするだけ（週1回ほど） |
| 収益 | なし（アフィリエイトではない） |

## 毎日の流れ

1. 毎朝、GitHub Actions が新しい動画・記事を集めてストックにためる（PR はない。記録は collect-data ブランチ）
2. 人が頼んだ時に、ストックからいちばん新しい7日分の候補を選んだ PR が届く → 人が確かめてマージ
3. 載せる日が来ると、その朝から「今日の一品」と新着に出る
4. 予定が残り2日分以下になると、Issue でお知らせが届く

くわしくは `docs/automation.md`（最初に人がする設定もここ）。

## ページの構成

- 夜の路地の絵／今日の一品／新着（画面幅に入るぶんの短冊）／品書き（焼き物・揚げ物・煮物・炒め物・小鉢・〆・**調味料が主役**・**✔（保存したもの）**、仕入れの札と「ひと手間」で絞り込み）／まとめて見る
- 料理の横の［保存］で、店主が見返したい品を保存できる。保存はそのスマホのブラウザの中だけ（ログインなし）
- スマホの縦向き専用。デザインとロゴは別に仕上げる

## ファイル

| 場所 | 中身 |
|---|---|
| `data/recipes.json` | ページに載せたもの・載せる予定のもの（`added` が載せる日） |
| `data/stock.json` | 集めたが、まだ載せていないもの（最新は collect-data ブランチ） |
| `data/seen.tsv` | 一度見た URL と、載せたか・載せなかった理由（追記のみ。最新は collect-data ブランチ） |
| `config/rules.toml` | 判定と分類のキーワード |
| `config/sources.toml` | YouTube の検索語と RSS のフィード |
| `scripts/` | 集める（collect）・7日分の候補を選ぶ（propose）・残り日数（remaining）・ページを作る（build_site） |
| `site/template.html` | ページのひな形 |
| `data/sample_links.csv`、`docs/classification-proposal.md` | 分類を決めた時の試しの114件と案 |
