# 店主に感想を聞く（2026-11-01〜）

初期版ができたので、実際に業務スーパーで仕入れている酒場の店主に感想を聞く。聞いた内容はそのまま Claude に渡し、直すことの優先順位を決める。

## 聞き方のコツ

- 最初は説明しすぎず、スマホでページを渡して黙って触ってもらう。どこを見て、どこで迷うかを見る
- 「使いますか？」より、実際にあったことを聞く（「最近、業スーの食材でメニューを増やしたのはいつ？どうやって決めた？」）

## 質問の例

### ふだんのこと
1. 業務スーパーで、何をどのくらいの頻度で仕入れているか
2. 新しいメニューは、どうやって思いついているか（YouTube・お客さん・ほかの店など）
3. メニューを考えるのは、いつ・どこでか（仕込みの合間、閉店後、仕入れの最中など）

### ページを見てもらって
4. 最初に目が行ったのはどこか
5. 「これ作ってみたい」と思った料理はあったか。それはなぜか
6. 品書き（焼き物・揚げ物…）と仕入れの札（肉・魚介…）、探すならどちらから探すか
7. 「調味料が主役」は役に立ちそうか
8. 店で出すには向かないと思った料理はあったか（家庭向けすぎる、手間がかかる、原価が合わないなど）

### 続けて使うか
9. 毎日1品ずつ増えるなら見に来るか。どのくらいの頻度で
10. ほかにあると助かる情報は何か（原価の目安、仕込み時間、何人前か、お酒との相性など）
11. 同業の知り合いに教えたいと思うか
