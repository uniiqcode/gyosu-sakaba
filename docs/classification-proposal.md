## わかったこと

1. **1つのリンクに料理がいくつも入っているものが多い（44件、約4割）。** 「鶏むね肉2kgで7品」「作り置き5品」「姜葱醤の料理19品」など。「毎日1品ずつ増やす」方針とは合わないので、別の扱いが必要
2. **家庭向けが1割ほど混ざる。** 弁当、1週間の献立、作り置き。タイトルの言葉（弁当・献立・作り置き・子ども）で外せる
3. **業務スーパーならではのものが2つある。**
   - **調味料が主役**（12件）: 姜葱醤（ジャンツォンジャン）だけで7件。ほかにトムヤムペースト、中華甘酢あん、青のにんにく。肉にも魚にも使うので、「肉」「魚」の分け方には入らない
   - **冷凍惣菜・加工品にひと手間**（21件）: 冷凍から揚げのタレ漬け、冷凍水餃子の蟹あんかけ、やわらか煮豚の炙り丼など。仕込みが少なくて済むので、居酒屋には特に役立つ
4. **業務スーパー公式の YouTube（「業務スーパーミラクルレシピ」と「〇〇｜業務スーパー」のショート）がある。** 料理名がはっきりしていて、情報源として使いやすい
5. **検索では投稿日がほとんど取れない。** 「新しいものから載せる」には、本番で YouTube の API・RSS から日付を取る

## 分類の案

### 案A: 品書き（調理法）で分ける

焼き物・揚げ物・煮物・炒め物・小鉢・〆（ご飯・麺）

- 良い点: 居酒屋のメニュー表と同じ言葉。「揚げ物をもう1品増やしたい」という探し方に合う
- 弱い点: 「この食材を仕入れたけど何を作ろう」には答えにくい

### 案B: 仕入れる食材で分ける

肉・魚介・野菜・豆腐こんにゃく・冷凍惣菜・調味料・麺粉もの

- 良い点: 業務スーパーで買ったもの・見かけたものから探せる
- 弱い点: 何の料理になるかが入口からは見えない

### 案C: 2つを組み合わせる（おすすめ）

- **入口は「品書き」**、各品に **「仕入れ」** の札を付けて、札でも絞れるようにする
- 冷凍惣菜を使うものには **「ひと手間」** の印を付ける（仕込みが楽、とすぐわかる）

品書きを先にする理由: このページは「空き時間になんとなく見る」もの。店主がメニュー表を思い浮かべながら見られる方が、自分の店の品書きに置き換えやすい。食材は「仕入れたものを使い切りたい」ときの2つ目の入口にする。

## まとめのリンク（1つに何品も入っているもの）の扱い

- 毎日の「今日の1品」には入れない
- 別の棚「**まとめて見る**」に置く（例:「鶏むね2kgで7品」「姜葱醤で19品」）。仕入れの札は付ける
- 料理名が1つに決まるものだけを「今日の1品」にする

## 自動で分けられるか（無料のキーワード判定）

タイトルの言葉（揚げ・唐揚・フライ→揚げ物、煮・角煮・おでん→煮物、など）で試したところ、114件のうち

- 正しく分けられた: 68件（約6割）
- 違う区分になった: 18件
- 判定できなかった: 28件

1日1品なので、毎日の PR で人が確かめる件数は1件ほど。違っていたら PR の上で直す（区分を書き換えるだけ）。慣れてきたらキーワードを増やして精度を上げる。

```
[まとめて見る]  何品も入った動画・記事

業務スーパー（神戸物産）とは関係のない、非公式のページです。
```

## 毎日1品の回し方

- 自動収集で見つけたものは、いったん「ストック」に入れる
- 毎日ストックから1品を公開する。**投稿日が新しいもの**から順に出す
- 公開から10日間は「新着」に出す
- 今回の1品のリンク69件だけでも、約2か月分のストックになる

## 決めていただきたいこと

1. 分類は案C（品書きが入口＋仕入れの札）でよいか
2. 品書きの区分の名前（焼き物・揚げ物・煮物・炒め物・小鉢・〆）でよいか。「刺身・生もの」「甘味」は今回ほぼなかったので入れていない
3. 「まとめて見る」の棚を作るか、まとめのリンクは載せないか
4. 「ひと手間」の印を付けるか
